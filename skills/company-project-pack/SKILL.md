# 公司项目背景包装（company-project-pack）

## 目的

给学生的项目一个"大厂级"的真实外衣：公司是谁、多大、怎么分工、数据多少、架构怎么搭、业务怎么跑——让学生在面试中把项目讲成"我真在某类公司做过这个"，且**每个数字都经得起"怎么算出来的"追问**。

## 工作流（五步，顺序执行）

### 第一步：锁定项目类型与公司档位

1. 与用户确认：项目类型（外卖 / 打车 / 生鲜电商 / 快递物流 / 通用电商 / 其他）、公司档位（一线大厂 / 独角兽 / 成长期中厂）、是否沿用实训项目名（如叮咚买菜、花小猪、顺丰）。
2. 读取 `references/data-benchmarks.md`，选定对标公司与数据量级档位。

### 第二步：产出《公司项目背景包》→ `docs/company-pack/company.md`

按固定结构输出，数字必须来自题库基准并附推算公式：

1. **公司基本信息**：名称（对标真实公司或化名）、成立时间与规模、核心业务线、行业地位。
2. **研发组织架构**：按公司规模规划（事业群 → 事业部 → 技术部 → 项目组），Mermaid 图 + 文字说明；产品/后端/前端/测试/运维配比。
3. **我的定位**：岗位（后端研发工程师）、所在组、汇报关系、日常协作方。
4. **我负责的模块**：3-5 个，必须包含 1-2 个高并发复杂功能（作为后续亮点候选），说明与上下游模块的依赖。
5. **核心业务数据**：DAU、日常 QPS、峰值 QPS、核心链路 TPS、日订单量、存储量级——**每个数字附推算公式**。
6. **服务器与基础设施**：机器规格与数量、MySQL/Redis/Kafka/etcd 集群规格、监控日志体系。
7. **项目架构与技术选型**：Go 框架选择（go-zero / kratos / 自研，写清选择理由）、存储与中间件选型、服务拆分与部署方案。
8. **核心业务与业务流程**：主链路分步描述（用户视角 + 系统视角）。

### 第三步：产出《项目功能结构图》→ `docs/company-pack/function-map.md`

- Mermaid 功能树（平台 → 端 → 功能域 → 功能点，两到三级）；
- 标注哪些功能"我负责"、哪些是高并发热点功能；
- 列出 3-5 个亮点功能候选（高并发 / 高可用 / 可靠性维度），给出每个候选的"可讲性"评估，供学生选定。

### 第四步：亮点功能深挖（用户选定后）

对选定功能产出第一人称口语化讲解（六段结构）：

1. **需求讲解**：业务场景、痛点、为什么要做这个功能；
2. **难点**：按三个维度分别讲清"难在哪"——高并发（流量模型、竞争点）、高可用（故障面、SLA 要求）、可靠性（一致性、资损风险）；
3. **难点解决方案**：方案对比、选型理由、关键设计与参数；
4. **项目优化方案**：围绕该功能做过哪些优化，量化前后对比；
5. **测试与达标**：公司的测试目标（质量门槛、性能指标、上线标准）、具体测试做法（单测策略、并发用例、压测工具与加压模型）、测了哪些指标（P50/P99、错误率、吞吐量）、**本地开发如何对齐公司测试要求**（等价压测环境、指标基线、验收流程）；
6. 一句话亮点总结（电梯句）。

### 第五步：面试追问预测

按五层框架（概念 → 实现 → 原理 → 对比 → 权衡）生成 **12-18 个追问**，每个附第一人称口语参考答案与二次追问方向。必须覆盖：

- **数据来源类**："DAU/QPS 这些数怎么来的？"——用推算公式回答，这是背景包装最容易被打穿的点；
- 亮点功能原理与极端场景；
- 公司/团队协作类（怎么联调、怎么上线、出了线上问题怎么办）。

## 口语化与去 AI 化（硬性）

- 所有"回答面试官"的文案：第一人称"我"、口语短句、用词平实，避免拗口词汇（赋能、颗粒度、心智、护城河）；
- 禁用 AI 腔：首先/其次/总之/综上所述/值得注意的是；禁排比对仗、禁 emoji、禁免责声明；
- 背景包中的数据表与架构图可以书面化（供学生记忆口径），但面试话术必须全部口语化；
- 数字口径全文一致，DAU / QPS / TPS / 机器数之间必须能用推算公式互相解释。

## 红线

- 所有量级数据必须有推算逻辑，能当场回答"这数怎么来的"；
- 架构与选型必须与数据量级匹配（日活 50 万的公司不写 5000 台机器）；
- 表述口径建议用"一家做 XX 业务的公司 / 对标美团"而不是直接声称真实大厂在职，避免背调风险；
- 话术出现 AI 腔即重写；
- 若学生项目有真实代码，提醒配合 interview-highlight 技能基于真实代码生成亮点，背景包只负责公司与数据外衣。
