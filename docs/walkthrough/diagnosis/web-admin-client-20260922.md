## 二、完成这个需求主要存在的问题（按严重度排序）

1. **竞态条件意识不完整（边界与失败场景思维缺失，轻）** —— 第 2 题答出了"并发刷新导致 refreshToken 失效、跳登录"这一层，但没有意识到第二层竞态：没有单飞时 5 次刷新各自拿到不同的新 token 对，5 次 `setSession` 先后执行会互相覆盖，可能把已生效的新 token 覆盖回旧的。证据：学生原话只讲到"refreshToken 一次性失效，所有请求鉴权失败跳登录"（第 2 题）。
2. **波及面清点有遗漏（实现细节不熟，轻）** —— 第 4 题答出了拦截器判断条件和提示逻辑联动，但漏了 `client.ts:93` `throw new ApiError('M6-E-0002', ...)` 这处硬编码字符串。证据：学生原话"错误日志、提示逻辑同步调整"未覆盖该常量（第 4 题）。
