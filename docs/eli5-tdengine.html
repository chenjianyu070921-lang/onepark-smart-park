🗄️ 为什么用 TDengine？

"用小朋友能听懂的话，讲个大人的事"

第一关：幼儿园里有 1 万个小朋友 🧒🧒🧒

⏰ 每秒都在举手报告

"老师我饿了！" "老师 25 度！" "老师我用 5 度电！"

👉 这些"小朋友"就是园区里的设备：电表、水表、传感器

第二关：用一个本子记会怎样？📒

📔 MySQL = 一本大本子
📔
MySQL
所有人挤一本本子
写得慢 ❌
翻得慢 ❌
本子塞爆 💥
➡️
📚
TDengine
每人一本小本子
写得快 ✅
找得快 ✅
还有模板 ✅

第三关：四种"本子"大比拼 🥊

📔
MySQL
记事本
什么都能记
但记日记太慢
🧻
Redis
便利贴
贴墙上超快
但只能记几句
📖
InfluxDB
日记本
专门记日记
但全班一起算就慢
📚
TDengine
班级作业本
每人一本 (子表)
格式一样 (超表)
全班算分超快 🚀

第四关：TDengine 的两个魔法 ✨

📋
魔法1：超表
模板本

老师先画一个格式：
"姓名 ___ 分数 ___"

所有小本子都照着画
📒
魔法2：子表
每人一本

小明一本
小红一本
互不挤占
翻得飞快

💡 想算"全班今天平均分"？
老师不用一本本翻，一把抓出来一起算！

🔌
