## 二、三性六讲讲解能力

**不会讲**。徐家祥用三性六讲框架讲不下来"用户鉴权 + 网关中间件"，输入输出、依赖链路、异常分支、性能风险这几条线串不起来，得接着练。

主要问题：
- 说不清 JWT payload 里有啥，也讲不明白 access_token 和 refresh_token 怎么配合续期
- 调用链讲不全：网关中间件怎么解析、怎么注入 ctxdata、logic 层怎么读，整条线断的
- 异常场景想的太少，就知道个密码错，Token 过期、黑名单命中、Redis 挂了降级这些都想不到
- 性能问题基本说不出来，不知道权限缓存为啥要做、连接池参数有啥用
- 安全方面说不出 JWT 签名怎么回事、黑名单有啥用

## 三、优化短板

只做了点 Token 黑名单相关的，整体优化思路没有。

可补充方向：

1. **MySQL 侧**：连接池参数、慢 SQL 排查、索引优化、分页优化
2. **Redis 侧**：热 key / 大 key 治理，缓存穿透 / 击穿 / 雪崩防护，用户权限缓存，TTL 策略优化
3. **接口侧**：限流、参数校验、超时控制
4. **链路侧**：RequestID 全链路追踪、错误码规范化、审计日志
5. **中间件**：gRPC 超时、重试配置
6. **存储**：软删除、审计日志、批量操作优化
