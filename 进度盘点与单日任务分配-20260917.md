## 第三部分：当日整体核心目标

**一句话目标**：打通「设备注册 → 影子创建 → event-dispatcher 投 Kafka → alarm/workorder 自动建单 → dashboard 大屏展示」端到端主链路（17/17 服务已编译通过，今日主攻联调）。

**主链路打通路径**：



```
设备 TCP/MQTT 上报 → gateway-service 认证 → shadow-service 写 reported

&#x20; → event-dispatcher 分类 → Kafka alarm-event + device-telemetry

&#x20; → alarm-service 判活 / workorder-service 自动建单

&#x20; → dashboard-service 并发 gRPC 聚合 device+workorder+alarm+energy

&#x20; → 大屏 wsserver 推送
```

## 第六部分：当日统一验收标准

### 单模块验收



* `go build ./...` 通过（device-service 必须上午通过）

* P0 接口可调用（curl 返回 200）

* 数据真实落库（MySQL/TDengine 有记录）

### 全链路验收（端到端 6 步）



1. 向 gateway-service 模拟一条设备 TCP/MQTT 上报；

2. shadow-service reported 字段更新；

3. event-dispatcher 向 Kafka `alarm-event` 投递；

4. workorder-service 自动落一张待派单工单；

5. dashboard-service `/overview` 返回工单总数 +1；

6. alarm-service WebSocket 向前端推送一条告警。

6 步全部手动走通 = 主链路验收通过。
