# 环境变量对照表（`.env.example` ↔ 各服务 `etc/*.yaml`）

> 用途：保证 `deploy/.env.example` 中定义的键，与各服务 `etc/*.yaml` 里 `${VAR}` 占位符**一一对应**，避免容器启动时占位符解析为空导致连不上中间件/库。
> 核对方式（可复现）：
> ```powershell
> # 提取所有 yaml 占位符
> Select-String -Path gateway\etc\*.yaml,app\*\etc\*.yaml -Pattern '\$\{([A-Za-z_][A-Za-z0-9_]*)\}' -AllMatches |
>   % { $_.Matches } | % { $_.Groups[1].Value } | Sort-Object -Unique
> # 提取 .env.example 键
> Get-Content deploy\.env.example | ? { $_ -match '^\s*[A-Za-z_][A-Za-z0-9_]*=' } | % { ($_ -split '=')[0].Trim() } | Sort-Object -Unique
> ```
> **结论：占位符 39 项，`.env.example` 键 82 项，缺失 0 项（本次已补齐 24 项）。**

## 五、部署用法

```bash
# 1) 复制并改真实值（尤其密码、密钥、外部地址）
cp deploy/.env.example deploy/.env

# 2) compose 用 --env-file 做变量替换；服务只接收 compose 中 environment: 显式列出的键
docker compose --env-file deploy/.env -f deploy/docker-compose.yml up -d

# 3) 静态部署（非 compose，直接 go run / 二进制）时，导出 .env 到进程环境
set -a && . deploy/.env && set +a
```
